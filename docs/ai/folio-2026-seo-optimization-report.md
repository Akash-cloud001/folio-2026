## 2. Critical issues (P0 — fix before indexing)

### 2.1 Default root metadata

**File:** `src/app/layout.tsx`

```ts
title: "Create Next App",
description: "Generated by create next app",
```

**Impact:** Every page without a title template inherits wrong branding in SERPs and browser tabs for `/`.

**Fix:**

```ts
export const metadata: Metadata = {
  metadataBase: new URL('https://YOUR-DOMAIN.com'),
  title: {
    default: 'Akash Parmar — Full Stack Developer',
    template: '%s · Akash Parmar',
  },
  description:
    'Full stack developer portfolio — interactive desktop UI, Next.js, React, and selected CTO case studies.',
  keywords: ['Akash Parmar', 'full stack developer', 'Next.js', 'React', 'portfolio'],
  authors: [{ name: 'Akash Parmar', url: 'https://github.com/Akash-cloud001' }],
  openGraph: { /* see section 4 */ },
  twitter: { card: 'summary_large_image' },
};
```

Add `src/app/page.tsx` metadata by splitting: server wrapper with metadata + client `DesktopHome` child, **or** export metadata from a thin server `page.tsx` that imports the client component.

### 2.2 No sitemap or robots

**Missing:** `src/app/sitemap.ts`, `src/app/robots.ts`

**Impact:** Slower discovery; no crawl hints for case studies vs home.

**Fix (example sitemap):**

```ts
import type { MetadataRoute } from 'next';

const base = 'https://YOUR-DOMAIN.com';

export default function sitemap(): MetadataRoute.Sitemap {
  const slugs = ['folio-2026', 'tradzu', 'my-forex-firms', 'nestingo'];
  return [
    { url: base, lastModified: new Date(), changeFrequency: 'monthly', priority: 1 },
    { url: `${base}/case-studies`, changeFrequency: 'weekly', priority: 0.9 },
    ...slugs.map((slug) => ({
      url: `${base}/case-studies/${slug}`,
      changeFrequency: 'monthly' as const,
      priority: 0.8,
    })),
  ];
}
```

```ts
// robots.ts
import type { MetadataRoute } from 'next';

export default function robots(): MetadataRoute.Robots {
  return {
    rules: { userAgent: '*', allow: '/' },
    sitemap: 'https://YOUR-DOMAIN.com/sitemap.xml',
  };
}
```

## 3. High priority (P1 — first week post-launch)

### 3.1 Open Graph & Twitter cards

**Current:** No `openGraph` or `twitter` anywhere.

**Recommendations:**

- **Global OG image:** 1200×630 — name, role, optional desktop screenshot (`/public/og-default.png`)
- **Per case study:** Use existing cover images (`/projects/folio-2026/landng-page.png`, etc.)
- Set `openGraph.type: 'website'`, `locale: 'en_IN'` or `en_US`

```ts
openGraph: {
  title: 'Akash Parmar — Full Stack Developer',
  description: '...',
  url: '/',
  siteName: 'Akash Parmar Portfolio',
  images: [{ url: '/og-default.png', width: 1200, height: 630, alt: '...' }],
},
twitter: {
  card: 'summary_large_image',
  creator: '@Akash_cloud001',
},
```

Case study pages can extend metadata:

```ts
export const metadata: Metadata = {
  title: 'Tradzu — CTO Case Study',
  openGraph: { title: '...', images: ['/projects/tradzu/lading-page.png'] },
};
```

### 3.3 Homepage crawlability

The OS metaphor hides content from static HTML. Mitigations (pick one or combine):

1. **Server intro block** — Hidden visually or above fold: one `<h1>`, 2–3 sentences, link to `/case-studies` (can be `sr-only` if design requires, but visible text is better for SEO).
2. **Split `page.tsx`** — Server component exports metadata + minimal semantic HTML; client `Desktop` as child.
3. **`noscript` fallback** — Plain links to case studies and mailto (last resort).

Re-enable **Hero** window or add equivalent visible `h1` on desktop (“Akash Parmar — Full Stack Developer”).

### 4.4 Performance & Core Web Vitals (SEO indirect)

| Factor | Risk |
|--------|------|
| WebGL `DitherBackground` | LCP / GPU on low-end mobile |
| Autoplay video (`folio-2025/vdo.mp4`) | Bandwidth; lazy below fold |
| GitHub API client fetch | Delayed content in About; not blocking meta |
| Duplicate video in `src/app/case-studies/folio-2025/` | Bundle bloat risk — remove from `app/` |

**Actions:** Lazy-load R3F on interaction or `dynamic(..., { ssr: false })` if metrics fail; compress video; preload only poster.
